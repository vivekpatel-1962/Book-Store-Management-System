# 📚 Book Store Management System

This is a **Book Store Management System** built using **Python** with a focus on seamless interaction with a **MySQL database**. It provides a comprehensive platform for managing book inventory, customer purchases, and sales records in a structured and user-friendly manner.

## ✨ Unique Feature

- **Dual-Role Functionality**: Supports both **Admin** and **Customer** roles with tailored functionalities for effective store management and a smooth shopping experience.

## 🚀 Features

### Admin Panel:
- Add, update, or delete book records in the inventory.
- Generate sales reports with visualizations using **Matplotlib**.
- Monitor low stock alerts for better inventory management.

### Customer Panel:
- Search for books by name or browse available books.
- Add books to a cart and proceed to checkout.
- Automatic stock updates after purchases.

### General:
- **MySQL Integration** for robust data storage and retrieval.
- Validations for user inputs like email and phone numbers.
- Dynamic creation of database and tables if not already set up.

## 🛠️ Technologies Used

- **Python**: Core programming language for the project.
- **MySQL**: Database for storing book, customer, and sales data.
- **Matplotlib**: For visualizing sales data.
- **Re (Regular Expressions)**: Used for validating email and phone inputs.

## 📖 How to Use

1. Clone the repository from GitHub.
2. Install required Python libraries (`mysql-connector`, `matplotlib`).
3. Run the `book_store.py` file.
4. Log in as either:
   - **Admin**: Manage inventory and view reports.
   - **Customer**: Browse books, add to cart, and checkout.
5. Follow the prompts to interact with the system.
